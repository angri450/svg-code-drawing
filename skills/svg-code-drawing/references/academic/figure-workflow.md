# 论文图工作流

## 第 0 步：图的契约

动笔前写完这五行：

```text
Results 级问题：
图级主张（一句话）：
什么证据能推翻它：
决定性证据（哪个面板承载）：
面板序列（a/b/c…各自角色）：
```

图是视觉论证。主证据给最大面板和最高视觉权重，支撑证据次之，背景/对照更弱。
超过 9 个面板拆图；每张主图回答一个 Results 级问题。

## 变体策略

一次出 2–3 版，同内容不同排布。

| 布局轴 | 适用 |
|---|---|
| 横向流 | 顺序叙事 |
| 网格 | 多条件对比 |
| 英雄面板+侧栏 | 一个主结果+支撑 |
| 上下两排（示意在上、数据在下） | 先讲机制后给数据 |

| 风格轴 | 特征 |
|---|---|
| 干净极简 | 白底细线无填充 |
| 色彩点缀 | 关键元素给 Wong 板强调色 |
| 暖灰 | #F8F6F3 底+柔和强调 |
| 高对比 | 强边框+饱和强调 |

## 面板与排版纪律

- 字母序 a→b→c 排布；阅读序左→右、上→下；圆形布局仅限环形流程。
- SVG text 的 y 是基线。面板字母基线 = 内容区顶边 − 2.5mm；第一排面板上方留 7mm 头空；所有文字完全落在父容器内。
- 面板框内文字距框至少 1mm；箭头全长至少 10mm、两端距元素至少 3mm；标签在横箭头上方 3.5mm、竖箭头左侧 3.5mm，不压线。
- 坐标一律 `round(x, 1)`；每个面板独立 `<g id="panel-x">` 分层。

## 图注（Legend）规范

固定骨架：

1. `Fig. N | ` 加粗体名词短语总标题，点名整图内容。
2. 按 a/b/c 逐面板描述，现在时、电报体；视觉事实用现在时，制作方法用过去时。
3. 统计口径写进图注：`mean ± s.e.m. (n = 3); one-way ANOVA with Tukey correction`。
4. 数据可得性套话置尾（可选）。

图注自含：离开正文单独可读，颜色/形状映射、样本量、单位、关键编号都写进图注。
末句可以收拢主张（"…表明这些模型学到的是全局结构模式而非物理规律"），但只在面板真支持该推断时使用。
图内图例条目用显示标签：首字母大写、专名保留原拼写（XGBoost 不是 Xgboost），不自动 title-case。

## 交付前 QA

1. 结构：面板字母齐全且按字母序；viewBox 符合目标期刊版面。
2. 文字：字号全在 5–8pt 区间；无文字压线或出界；基线居中用 0.35 系数。
3. 色彩：不超过 7 色；跑色盲亮度对比检查（`scripts/audit_figure.py`）；灰度打印可读。
4. 论证：每个面板都有不可删除的理由；图注自含；删到不能再删。
