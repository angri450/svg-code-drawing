# 自由曲线的三层拆解：趋势、摆动、包络

任何看起来「自由流畅」的设计曲线，都能拆成三层。设计师徒手画出来的河流、山脊、飘带、卷轴，本质上都是这三样的叠加，只是他没说出来。

## 什么时候用这篇

- 要从一张参考图复刻一条自然曲线
- 要让一条装饰线看起来「像活的」，不是几何图形
- 已经用正弦硬拟合，结果要么太规律、要么抖成噪声

## 一、三层各管什么

| 层 | 回答的问题 | 典型函数 | 河流例 |
|---|---|---|---|
| 趋势 `c(x)` | 整体往哪走 | 一条斜线 | 左低右高，稳稳上扬 |
| 摆动 `m(x)` | 弯的节奏 | 变频正弦 | 谷→峰→谷→峰，间距越拉越大 |
| 包络 `h(x)` | 本身多粗 | 线性或二次 | 左窄右宽，右边甩出一条宽带 |

三条边只从一个母体派生：

```
center(x) = c(x) + m(x)
upper(x)  = center(x) + h(x)
lower(x)  = center(x) − h(x)
```

**两条边是同一个母体加减同一个 `h`，所以永远同步起伏、永不捏拢。** 这是结构性保证，不是调参调出来的。反过来，上下各写一个独立的 `sin`，相位一错就成麻花。

## 二、摆动怎么做出「间距越来越大」

先说结论：**波长递增等于频率递减，而频率不能直接乘进正弦里。**

第一反应通常写成 `sin(f(x)·x)`。快速实验会发现频率在每一点都在变，波形抖成噪声。原因是相位不是频率乘位置，而是频率的积分。

推导：

```
瞬时频率线性滑落   f(x) = f₀ + (f₁ − f₀)·x / L
相位是频率的积分   φ(x) = 2π · [ f₀·x + (f₁ − f₀)·x² / (2L) ]
```

所以频率线性，相位就是二次。河流那条：

```
g(x) = x/620 − (1/620 − 1/2600)·x²/3840
```

`1/620` 是左端频率，对应波长 620 像素，密；`1/2600` 是右端频率，波长 2600，疏。分母的 3840 来自 `2L`，L 是曲线总长 1920。

**漏掉这个 2，波长递增速率会差一倍，是这类公式最常见的翻车点。**

验证：`g(1920) ≈ 1.92 圈`，加上初始相位，全图落在 2.3 个弯左右。

## 三、初始相位怎么定：对表

参数都对了，波形位置还是可能整体偏左或偏右。这时候不要凭感觉调，用原图的地标反解。

1. 从原图读一个确定的位置，比如第一个波谷在 `x ≈ 265`
2. 解「波形什么时候到达第一个谷」：谷底相位是 `3π/2 + 2kπ`
3. 反推 `φ₀`

```python
def solve_phase0(x1, f0, f1, L, trough=True):
    target = 3 * math.pi / 2 if trough else math.pi / 2
    base = 2 * math.pi * (f0 * x1 + (f1 - f0) * x1 ** 2 / (2 * L))
    k = round((target - base) / (2 * math.pi))
    return target + 2 * math.pi * k - base
```

河流的 `φ₀ = 3π/4 ≈ 2.356`。调这个数等于把整条蛇在 x 轴上滑动，直到蛇头对准原图的蛇头。

## 四、校准顺序

骨架节奏对上了，感觉就对上了。按这个顺序调，不要一上来改振幅。

| 原图地标 | 对应参数 | 调它会怎样 |
|---|---|---|
| 谷₁ 的位置 | `φ₀` | 整条曲线左右平移 |
| 峰₁ 的位置 | `f₀` | 左端密度变密或变疏 |
| 谷₂ 的位置 | `f₁` | 右端疏密 |
| 右端上扬出画 | `c` 的斜率加 `h` | 收口张开或收拢 |

## 五、整条河的完整参数

```python
g(x) = x/620 - (1/620 - 1/2600) * x**2 / 3840   # 相位
S(x) = (50 + 0.02*x) * sin(3*pi/4 + 2*pi*g(x))  # 摆动，振幅随 x 长
C(x) = 455 + 0.065*x                            # 趋势
H(x) = 112 + 0.046*x                            # 半宽

U(x) = C(x) + S(x) + H(x)                       # 上缘
L(x) = C(x) + S(x) - H(x)                       # 下缘
```

`S(x)` 的振幅自己也在长（50 到 88），所以右边摆得比左边开，不是衰减。宽度靠 `H(x)` 线性撑开。

## 六、常见错误清单

1. 写成 `sin(f(x)·x)`，波形抖成噪声。相位要积分。
2. 二次项漏掉 `/2`，波长递增速率翻倍。
3. 上下缘各自写一套摆动，相位一错就成麻花。必须共用母体加减包络。
4. 先调振幅后调相位，越调越乱。先对表定 `φ₀`，再改 `f₀` 和 `f₁`。
5. 想要「先快后慢变粗」，包络用二次 `h0 + k·x − q·x²`。斜率比控制在 2:1 左右，超过 3:1 视觉上会像前段猛长后段停住。
