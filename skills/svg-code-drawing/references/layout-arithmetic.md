# 布局算术与连接线规矩

每个位置都有公式可算，不靠目测。

## 居中

```
内容宽 = 最右元素右缘 - 最左元素左缘
左外边距 = (viewBox宽 - 内容宽) / 2
```

标题居中于内容中心，不是 viewBox 中心。内容不对称时两者不重合，标题随内容走。

## 事后平移

画完发现整体偏移时，把全部内容包进 `<g transform="translate(dx,0)">`，`dx = (右外边距 - 左外边距) / 2`（右挤为正、左挤为负）。
代价是文件坐标不再等于渲染位置，后续编辑要扣除偏移；大改前把偏移折回坐标并删掉 g。

## viewBox 页边距

标题算内容的一部分，边距从标题量：

```
标题 y = 边距 + 字体上缘 ≈ 边距 + 字号×0.75
viewBox 高 = 内容最低点 + 边距
推荐边距 20~25px
```

## 盒子尺寸与文字基线

盒高 = 字号 × 3（上内边距约一个字号 + 字形高约一个字号 + 下内边距约一个字号）；行高 = 字号 × 1.5，每多一行加 1.5×字号。

SVG 的 text y 是基线不是字顶。盒内垂直居中：`y = 盒中心y + 字号 × 0.35`（0.35 是光学中心到基线的经验系数）。

两个系数用途不同：×0.75（上缘）用于从顶部定位的元素，如标题；×0.35（基线偏移）用于盒内居中。

同行盒高差不超过 60px；同列盒共中心线；外盒 = 内容 + 2×内边距。

## 连接线规矩

- 同轴横平竖直用直线 `L`；拐弯或绕行用 C/Q 曲线，不用直角肘。
- 离轴连接的转折用 r=8 圆角。
- 标签遮罩与线之间留 6-10px 可见缝。
- 交叉跳弧，半径错开；同一边缘上的多个连接点相距至少 12px。
- 线不从非终点盒身后穿过；避不开时虚线化，标签放可见端。
- 箭头先画、盒子后画，盒盖住线的多余部分，端点贴边。
- 同级或相邻盒间距至少 25px（推荐 25-30）；文字距线 10-20px。
- 图例放图体外底部条带，不与内容重叠；箭头标签背后垫不透明矩形。

## 分组盒规格

一张图内所有虚线分组盒保持一致：`stroke-dasharray="6,4"`、rx 8-12、fill `#f8fafc` 或 none、内边距 15-20px、组标题字号 11px（正文 12px）。
标题放盒内左上角（x=盒x+10, y=盒y+14），次级文字色 `#64748b`。
盒高按"标题+内容"总高计算；带标题时内容下让 20-25px。
连接器指向一组元素时，终结在组盒边界上，不扎进某个成员。

## 交付前自查

1. 文字不压盒、不压线；线不穿盒（终点除外）。
2. 标题居中于内容中心；内容全部在 viewBox 内，不裁切。
3. 箭头先画、盒子后画；每个箭头标签有不透明底衬。
4. 交叉有跳弧；同边缘连接点相距至少 12px；线不从非终点盒身后过。
5. 分组盒四要素一致；图例在底部条带外。
6. `svg` 带 `role="img"` 与 `aria-labelledby`，`<title>` 是第一个子元素。
7. 盒内居中用 0.35 系数，不是把 y 摆在盒中心。
