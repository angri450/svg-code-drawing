# 生成 pptx 时的常见错误

用脚本生成 pptx 时，问题集中在四处。生成完按这个顺序查一遍，比事后逐页翻效率高。

## 一、文字被裁或位置偏移

1. **不要写 `spc` 字距。** OOXML 的 `a:rPr@spc` 在 LibreOffice 里会把文本推出框外再按框裁切，框宽从 196 加到 364 像素，裁切点一个像素都不动。字距靠字号和位置调。
2. **文本框设 `auto_size = MSO_AUTO_SIZE.NONE`。** 默认是随文字缩，宽度压缩后中心点不动，通栏大字会从画面中间开始排，不是从左边距。
3. **中文字体同时写 `a:latin` 和 `a:ea`。** 只设 `font.name` 只写西文属性，中文字符退回主题默认字体，换到没装思源的机器会掉成等线。
4. **宽度估算留 30% 余量。** 中文全角约 1em，Noto 系列实际渲染更宽，`text_width × 1.3 + size × 1.5` 才不裁。

## 二、图表不听话

1. 数据页用原生图表：折线 `LINE_MARKERS`，柱子 `COLUMN_CLUSTERED`，瀑布用 `COLUMN_STACKED` 加透明 base 系列模拟。
2. 图表区默认带边框，给 `c:chartSpace` 插 `c:spPr`，里面放 `a:noFill` 和 `a:ln/a:noFill`，位置在 `c:chart` 之后。
3. 占位系列要关数据标签，否则瀑布图会冒出一串 0。
4. `Chart` 对象没有 `format` 属性，图表区填充只能走 XML。

## 三、渐变方向反了

1. `gradient_stops` 的索引顺序和视觉方向相反，`angle=90` 时 `stops[0]` 落在底端。要顶部透明、底部深色，赋值写成 `(a_bottom, a_top)`。
2. 多层半透明矩形叠不出渐变，层与层之间硬切，会出现色带。要用 `gradFill` 两个 stop 各带 alpha。
3. 图片做波浪、圆形、拱形裁切只能用 PIL 生成蒙版，四倍超采样再 `LANCZOS` 缩小，否则边缘是阶梯。

## 四、改完看不到变化

1. 先比对 pptx 的 md5，一样就是渲染了旧文件。
2. `grep -c "^def 函数名"`，数量大于 1 说明同名函数被覆盖，后定义的生效，前面的白改。
3. 构建输出不要整个重定向掉，保留 stderr，否则报错也看不见。
