# 教学示意图：把一个机制讲到别人一眼看懂

面向初学者的讲解图。读者不懂这个机制，看完图要能复述出「发生了什么、为什么这样」。这张图的价值不在信息密度，在**读图的顺序是对的**。

## 先定三件事

1. **这张图要替哪句话**：先写一句结论当标题，比如「倒位＝断＋转＋接；倒位环＝同源位点要对齐，染色体只好弯成环」。写不出这句话，说明这张图不该画。
2. **读者看完要能回答的问题**：一个问题一块内容，一块都不回答问题的删掉。
3. **这张图属于哪个系列的第几张**：同目录已有图先翻一遍，配色、字号、面板底色沿用同一套，别另起一套。

## 分块：一块一件事

按「读者该按什么顺序理解」切块，不按「内容有多少」切。

- 块与块之间从上到下就是阅读顺序，编号写进标题（①②③）。
- 每块自带标题和一句小结，读者跳着看也不丢线索。
- 一张图超过四块就拆成两张。塞不下的信息不是缩小字号，是该拆。

常见的三块结构：现象是什么 → 为什么这样 → 接下来会怎样。

## 同一个概念，同一种颜色

这是让图能被读懂的关键。同一批对象（基因、细胞、部件）在全图用同一套颜色，读者靠颜色就能跨块追踪。

- 颜色用来区分**类别**，不是用来区分**顺序**。顺序用位置和编号表达。
- 颜色不超过五种，多了读者分不清。
- 每种颜色配一个文字标签直接写在图上，别让读者猜。
- 一对对应关系用虚线连起来，并且注明这条线表示什么（「浅虚线＝配对关系」）。不注明的话，读者会把虚线读成交叉互换或者信号传递。

## 画「为什么」，不只画「是什么」

初学者卡住的地方通常在「为什么非得这样」。针对这个点单独给一块对照。

对照的常见形式：

- **正反对照**：正常型 vs 变异型，两行并排放，差异部分用虚线框圈出来。
- **顺序对照**：同一段序列在两种情况下的排列顺序，逐位对齐，同色对应。
- **要求对照**：先摆出「必须满足什么」（同源位点要一一对齐），再摆出「满足不了会怎样」（只能弯成环）。因果链一断，读者就卡住了。

## 画动作，别画比喻

涉及「怎么变成」的机制，用动作分解：

1. 起点状态，一条线带标号。
2. 断开的地方画叉，标出断点。
3. 中间段旋转或移动，箭头标出方向和角度。
4. 接回去的结果，终点状态。

每一步单独一步，中间不留空。读者跟得上每一步，才跟得上整体。

不要用「压塌」「拱桥」这类比喻代替动作。比喻画起来快，但读者看完还是不知道实际发生了什么。

## 配色与字号

- 主色深、正文浅，同类对象同色。参考同系列旧图，不自创。
- 正文不小于 14px，标签不小于 12px。
- 面板底色用极浅的填充加细描边，不要重边框。
- 高亮某一步用强调色（通常是红或琥珀），只用在真正要指的那一处。

## 自查：导出后必须把图读回来

写完 SVG 不等于验收。坐标算对了，不代表画面上没压字。

1. `export_png.py` 出 PNG。
2. **用图像读取工具把 PNG 读回来，亲眼看一遍。**
3. 盯四处：文字有没有压住别的字或被色块盖住、箭头有没有盖住标题、引线端点有没有指错对象、标注有没有和图里说的对不上。
4. 有问题改 SVG 坐标，重新导出，重新看。

这一步常能查出自动检测查不出的问题。`check_overlap.py` 查的是几何重叠，查不了「这段文字说的和图上画的对不对」「这个箭头该指谁」。

## 交付前自查

- 标题就是那句话结论。
- 每块有编号、有小结。
- 图例齐全，颜色含义在图上直接标了。
- 删掉所有「显然」「众所周知」式的词，读者不需要背景知识也能看。
- 缩小到实际阅读尺寸（比如手机上），文字还读得出来。
